# Pay Me on UPI: a multi-agent book writer

Take-home assignment for the Patel Group AI Engineer role. A multi-agent system (Planner, Researcher, Writer,
Editor, Fact-checker, Chief Editor) researches and writes a three-chapter book for first-time small-business
owners in India, with real, verified citations, and streams its work to a live dashboard.

**Status:** scaffolded; implementation in progress. The full design, milestones and cost plan are in
[docs/PLAN.md](docs/PLAN.md).
